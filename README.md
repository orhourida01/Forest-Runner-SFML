# 🌲 Forest Runner - 2D Survival Game

**Forest Runner** is a 2D side-scrolling survival game built with **C++** and **SFML 3.0.2** as part of the Object-Oriented Programming (OOP) module at the **Faculty of Sciences Semlalia (FSSM)**.

## 🕹️ Gameplay
In this game, the player controls a character navigating through a forest, avoiding obstacles and collecting coins to reach the final objective.
*   **Space / Up Arrow**: Jump.
*   **Down Arrow**: Crouch.
*   **Objective**: Survive for 50 seconds and collect as many coins as possible.

## 🛠️ Technical Features
*   **Language**: C++.
*   **Library**: SFML (Simple and Fast Multimedia Library) 3.0.2.
*   **OOP Principles**: Encapsulation, Inheritance, and Polymorphism for managing game entities.
*   **Dynamic Spawning**: Random generation of obstacles and coins.

## 📂 Project Structure
*   `src/`: All C++ source files (`.cpp` and `.h`).
*   `assets/`: Game resources including textures, fonts, and audio.
*   `CMakeLists.txt`: Build configuration file.
*   `Rapport.pdf`: Detailed technical documentation and UML diagrams.

## 🚀 How to Run
1. Make sure you have **SFML 3.0.2** installed on your system.
2. Clone this repository.
3. Compile using CMake or your preferred C++ IDE (VS Code, Visual Studio).
