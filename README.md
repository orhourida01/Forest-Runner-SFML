# 🌲 Forest Runner - 2D Survival Game

**Forest Runner** is a 2D side-scrolling survival game built with **C++** and **SFML 3.0.2**. This project was developed as part of the Object-Oriented Programming (OOP) module at the **Faculty of Sciences Semlalia (FSSM)**.

## 🕹️ Gameplay
Control the player to navigate through a dangerous forest, avoid obstacles, and collect coins to reach the final objective.
*   **Space / Up Arrow**: Jump to avoid ground obstacles.
*   **Down Arrow**: Crouch to avoid high obstacles.
*   **Objective**: Survive for 50 seconds and collect as many coins as possible.

## 🛠️ Technical Features
*   **Language**: C++.
*   **Library**: SFML 3.0.2.
*   **OOP Principles**: Implementation of Encapsulation, Inheritance, and Polymorphism.
*   **Dynamic Spawning**: Random generation of obstacles and coins for a unique experience each time.

## 📂 Project Structure
*   `src/`: C++ source files (`.cpp` and `.h`).
*   `assets/`: Textures, fonts, and audio files.
*   `CMakeLists.txt`: Build configuration.
*   `Rapport.pdf`: Technical documentation and UML diagrams.

## 🚀 How to Run
1. Install **SFML 3.0.2** on your machine.
2. Clone this repository.
3. Open the project in **VS Code** or your preferred IDE.
4. Compile and run using CMake.
